# Milestone 1 — User Authentication Module

## Overview
This milestone focuses on building a user authentication application using Streamlit, JWT, and Gmail OTP.

## Objectives
- User login and signup
- Mandatory-field, email, and password validation
- JWT-based session management
- Forgot password using a security question or email OTP
- User dashboard and logout
- Separate admin login and user listing

## Technology Stack
- Python
- Google Colab
- Streamlit
- JSON Web Tokens (JWT)
- Gmail SMTP for OTP delivery
- ngrok for public access
